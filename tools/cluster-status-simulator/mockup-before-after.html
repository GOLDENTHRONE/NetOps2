About the green “Ready” state In this safe mockup, green means Reachable — the cluster answered. It does not yet promise the door will open, so the label stays honest with a one-line caption. A fuller green Ready (“answered and your access works”) is possible later, but it needs the optional background sign-in check (#2) — a small extra request per cluster — so it’s deliberately left out of this no-risk set.
